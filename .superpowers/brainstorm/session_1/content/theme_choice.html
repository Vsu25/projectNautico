How should the Staff Panel handle visual themes?

Select if the admin panel should have its own professional design or match the member-side theme matrix.

A

Fixed Professional Slate Layout

A clean, focused admin interface (Slate/Blue/Indigo tones) optimized for reading tables and numbers. Supports light/dark mode, but doesn't change with Brutalist/Glass themes.

B

Inherit Global Themes

Matches the active global theme (Glass, Flat, or Brutalist). If the user switches to Brutalist, the staff backend also renders in the Brutalist style.
